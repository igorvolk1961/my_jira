# Артефакты системного аналитика — проект «Учебный проектный офис (УПО)»

Комплект аналитических артефактов для учебного проекта. Документы описывают систему, которая реализована в коде (`main.py`), и используются как учебный материал для курсов «Системный аналитик».

## Состав комплекта

| № | Артефакт | Файл | Назначение |
|---|----------|------|------------|
| 1 | Видение (Vision) | `01-vision.md` | Цели, границы, ценность продукта |
| 2 | Глоссарий | `02-glossary.md` | Термины предметной области |
| 3 | Заинтересованные лица и карта стейкхолдеров | `03-stakeholders.md` | Роли, власть/интерес, коммуникации |

## Связь с реализацией

Код и БД соответствуют приведённым артефактам. Полезно сопоставлять:
- модели данных — `main.py` (функция `init_db`, DDL);
- требования — страницы/маршруты приложения;
- справочники — выпадающие списки и раздел «Справочники».

> Комплект — иллюстративный учебный материал; полнота и глубина каждого документа адаптированы под учебный формат.

## Диаграммы (Mermaid)

Часть документов содержит Mermaid-диаграммы (рендерятся в GitHub/VS Code):
- **01** — контекстная диаграмма;
- **03** — матрица власти/интереса (quadrant);
- **06** — обзор вариантов использования;
- **09** — бизнес-процессы (flowchart);
- **10** — диаграммы состояний (stateDiagram);
- **11** — ER-диаграмма (erDiagram);
- **12** — схема навигации (flowchart).
