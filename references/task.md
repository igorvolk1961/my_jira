Простое приложение для управления проектами, задачами и персоналом.
Приложение предназначено для поддержки ролевых игр на курсах обучения профессии Системного аналитика.
Занятия на курсах происходят в форме вебинаров. Преподаватель в ходе занятия вызывает добровольцев из числа слушателей.
Назначает роли нескольким стейкхолдерам и одному системному аналитику.
Стейкхолдеры должны придумать проект, а системный аналитик набрать команду из числа добровольцев и смоделировать полный жизненный цикл выполнения одновременно нескольких проектов в ходе одного-двух занятий. В ходе выполнения преподаватель "подбрасывает" вводные, требующие оперативной реакции системного аналитика (форсмажор, изменение внешних условий, болезнь сотрудников, изменение конюнктуры, необходимость оперативного предоставления отчета по любому вопросу и так далее).
Приложение должно быть максимально простым, так как его должен иметь возможность оперативно скачать, установить, освоить и использовать каждый слушатель курсов, в свою очередь. При этом большинство слушателей - люди далекие от ИТ-сферы.
Слушатели для выполнения задач, поставленных системным аналитиком, могут использовать ИИ-чаты. Взаимодействие между "сотрудниками" - только голосом, сообщениями в телеграмм-канале и чате вебинара (у многих чат вебинара сильно тормозит). 
Опытные слушатели могут помогать коллегам, предоставляя им промпты для выполнения задач с использованием ИИ.
